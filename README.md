# MINI ClassIsland 集控增强组件

> [!CAUTION]
> **安全风险警告**：本插件运行在 ClassIsland 应用本体同级上下文中，具备极高的系统与客户端控制权限。安装并启用本插件后，受信任的集控服务器可获取本机详细硬件信息、修改应用设置、在运行时热更新与切换多套课表档案；在开启对应客户端权限开关后，集控服务器还可编辑自动化工作流、控制客户端更新、管理插件与主题，甚至执行任意外部代码或终端指令、捕获客户端屏幕截图、发送模拟鼠标点击以及读取本机运行进程清单。此外，本插件内置插件自我保护与应用本体抗停止保护机制，可能阻止非授权的进程终止或插件禁用操作。请仅在明确知悉上述安全风险且完全信任所接入的集控服务器管理员的前提下安装和使用本插件！

本组件用于配合 MINI ClassIsland 集控服务器，提供安全增强的集控指令承接、策略同步与终端运维支持。

## 核心特性

### 基础集控能力
- **详细硬件信息采集**：采集处理器、物理内存、存储磁盘、显示适配器、屏幕参数、网络接口及主板固件信息。
- **应用设置同步与管理**：支持集控默认设置实时同步、设置项增量变更与受控覆盖层管理。
- **运行时档案热更新与多档案管理**：支持在客户端同时维护多套课表档案，并在不重启应用的前提下实时切换或热更新当前课程表、时间表和科目数据。
- **接入与配对体验增强**：在加入集控窗口内直接展示配对码并支持低开销自动轮询审批状态；支持通过租户标识与班级标识快速接入集控。
- **网络漫游与策略保护**：锚定注册物理网卡地址，改善无线与有线网络切换或地址跳变时的重连速度；提供集控策略防篡改校验、插件自我保护及应用抗停止保护。

### 扩展运维能力
以下能力默认关闭，需在客户端集控选项中单独开启对应开关后方可执行：
- 编辑自动化工作流配置
- 控制客户端更新检查、下载与通道配置
- 管理客户端插件的安装、启用、禁用与卸载
- 管理客户端外部主题的安装、启用排序与实时加载

### 远程协助能力
以下高敏能力默认关闭，需在客户端集控选项中单独开启对应开关并经过端到端加密签名验证后方可执行：
- 执行受控外部脚本与指令
- 获取客户端屏幕画面截图
- 执行模拟鼠标点击与光标操作
- 获取客户端当前运行进程清单
